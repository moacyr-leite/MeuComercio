# Meu Comércio

Sistema simples de controle de estoque e vendas para pequenos mercados e comércios familiares.

## Objetivo

O Meu Comércio foi criado para ajudar pequenos comerciantes a controlarem produtos, estoque e movimentações de forma prática e intuitiva.

O sistema é focado em:
- simplicidade,
- acessibilidade,
- uso em celulares,
- facilidade para pessoas idosas.

---

# Tecnologias

## Frontend
- React
- PWA (Progressive Web App)

## Backend
- Python
- FastAPI

## Banco de Dados
- PostgreSQL

---

# Funcionalidades do MVP

- Cadastro de produtos
- Controle de estoque
- Entrada e saída de mercadorias
- Histórico de movimentações
- Login de usuários
- Busca rápida

---

# Público-alvo

- Pequenos mercados
- Mercadinhos de bairro
- Comércio familiar
- Usuários com pouca experiência em tecnologia

---

# Princípios de UX

O sistema será desenvolvido pensando em:
- botões grandes,
- navegação simples,
- pouco texto,
- alta legibilidade,
- poucos cliques.
